## 2. Интеграция 1С (ITSheff) <-> LensFlow
**Текущий статус: В ПРОЦЕССЕ (В приоритете)**
Пользователь отказался от ручного обмена через FTP/файлы. Мы настраиваем прямой REST/SOAP обмен с 1С ITSheff.

**Проблема:** 1С отказывается делать синхронизацию, пока в ней не будет создан "Узел обмена" (Exchange Node).
**Наше решение:** Мы проходим встроенный мастер настройки 1С ("Синхронизация через универсальный формат" -> "Подключение через Интернет").
- Мы создали фейковый SOAP-эндпоинт в Next.js: `src/app/api/onec/exchange/ws/[...service]/route.ts`.
- Этот эндпоинт имитирует интерфейсы `Exchange_3_0_2_1` и `Exchange_2_0_1_6`. Его задача — ответить 1С "Да, я готов", чтобы 1С создала узел обмена `LENSFLOW`.
- Учетные данные для мастера 1С:
  - Адрес: `https://lensflow-crm.vercel.app/api/onec/exchange`
  - Логин: `lensflow`
  - Пароль: `LensFlow2024!`
- **Последний фикс:** 1С при проверке выдала ошибку парсинга WSDL: `Элемент не найден GetVersions`. Мы добавили генерацию XSD схем (`<wsdl:types>`) в код `route.ts`. Фикс задеплоен.
